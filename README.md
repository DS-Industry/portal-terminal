# portal-terminal

# 1: Виртуальное окружение

перейти в главную папку проекта
(у меня /c/Dev/portal-terminal)

далее
для git bash:
```
python -m venv venv

source venv/Scripts/activate
```

Еще есть прикол у некоторых IDE, нужно самому вручную выбрать будет рабочую область 
с виртуальным окружением. У меня в VScode, например, справа в нижнем углу, есть надпись 
Python *Номер версии (область установки). Короче надо выбрать область именно с venv.

# 2: Установка зависимостей

Из той же папки запустить установку зависимостей

```
pip install -r requirements.txt
```

В этот же файл запиши те зависимости и модули которые нужно установить, 
типо для работы с Modbus, АТОЛ и так далее

# 3: переменные окружения

в той же главной папке проекта создать файл .env (пока что пустой)

# 4: Проверка запуска:

1) применить миграции БД:

```
python manage.py migrate
```

2) запустить локально

```
python manage.py runserver
```

3) Проверить доки

Перейти на http://127.0.0.1:8000/swagger

Перейти на http://127.0.0.1:8000/redoc

4) Проверить админку

в терминале при выключенном проекте запустить

python manage.py createsuperuser

далее дать имя admin
Почту admin@admin.com
пароль admin

далее перейти на http://127.0.0.1:8000/admin

Создать вручную программы с ценами

5) Тест

через постман отправить post запрос 

http://127.0.0.1:8000/api/create-order/

с телом

{
  "program_id": 1,
}

или

{
  "program_id": 1,
  "ucn": "000123456"
}

ucn - опционально.

Проверить админку.
